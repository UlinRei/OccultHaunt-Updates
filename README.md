# 暗夜集會 Occult Haunt

> 在月光下，異類們聚在酒館裡，用一副 15 張的牌決一勝負。

《暗夜集會》是一款雙人回合制的競技卡牌遊戲，支援 **Windows** 與 **Android**。你會扮演一名「異類」，用牌組裡的卡牌、角色的共鳴與儀式，以及場上的召喚物，把對手的耐力打到 0。

目前處於 **測試階段（Beta）**，內容與數值會持續調整。測試期間取得的貨幣與抽卡紀錄，正式上線時會重置，設定與偏好會保留。

## 立刻開始

1. 到 [Releases 發布頁](https://github.com/UlinRei/OccultHaunt-Updates/releases) 下載最新的版本。
2. **Windows：** 下載 `OccultHaunt.exe`，放在你喜歡的資料夾後直接執行。
3. **Android：** 下載 `.apk` 並安裝，系統若詢問「允許安裝未知應用程式」，請允許這個瀏覽器或檔案管理員。
4. 開啟遊戲，選擇語言與登入方式。你可以用 **訪客** 直接開始，之後再綁定 Google、Discord 或 Steam 帳號，換裝置也能取回收藏與牌組。

之後遊戲會自己檢查更新，有新版本時在「公告」裡按「立即更新」就好。

## 這是什麼樣的遊戲

### 目標
把對手異類的耐力降到 0，你就獲勝。異類的初始耐力是 30。

### 牌組
- 一副牌 **15 張**，同名卡最多 **2 張**。
- 先選一個 **月相**，牌組只能放該月相與中立的卡牌。月相代表流派：紅月偏反擊與回復，藍月偏召喚物與連動攻擊，紫月偏封鎖與陷阱，黑月偏詛咒與狀態減益，白月偏護盾與減傷。
- 每名 **異類** 有自己的專屬卡，放進牌組達到條件就會鎖定該角色出戰。沒有鎖定角色時，使用該月相的「無面者」。

### 對局怎麼進行
- 每位玩家開局抽 4 張，可以選擇重抽一次。後手玩家第一回合會獲得一張【預感】。
- 每回合開始時，活性（出牌用的資源）會補滿，活性上限會隨回合增加，最高 10。
- 用活性打出手牌，卡牌可以造成傷害、回復、施加狀態、召喚 **召喚物** 到 **林地**（雙方各 5 格）。
- 召喚物可以攻擊對手，被攻擊的召喚物會反擊。
- 異類的 **靈性** 充滿後，可以施放強力的 **儀式**。
- 手牌上限 8 張，牌庫抽完會洗回棄牌堆並受到疲勞傷害。

### 卡牌與詞條
卡牌上有許多詞條，例如：

- **吟詠：** 打出後持續數個回合，符合條件時觸發。
- **延時：** 效果延後幾個回合才發動。
- **歧路：** 從多個選項中選一個執行。
- **預備、迅捷、遲緩：** 影響卡牌的代價。
- **銷毀、虛無：** 打出或回合結束後直接從遊戲中移除。

遊戲內點擊卡牌或詞條就能看到說明，也有「新手說明模式」用白話解釋。

## 遊戲模式與功能

- **AI 對戰：** 單人練習，有多種難度。
- **連線對戰：** 輸入對方的 4 位數房間代碼就能連線，可以用網際網路或區域網路。
- **回放：** 對局會自動記錄，隨時回顧。
- **牌組分享：** 產生牌組代碼或短代碼，或直接傳給連線中的對手。
- **好友：** 搜尋暱稱或 #TAG 加好友，也可以複製邀請連結。
- **帳號：** 訪客、Google、Discord、Steam。收藏與牌組跟著帳號走，換裝置不怕遺失。
- **語言：** 繁體中文、English、简体中文、日本語。
- **教學：** 第一次進遊戲會有引導，酒保普羅米會帶你熟悉酒館。

## 常見問題

**一定要登入嗎？** 不用。訪客就能玩，但訪客資料只存在這台裝置，建議到「設定 > 帳號」產生恢復碼或綁定帳號。

**換手機或電腦怎麼辦？** 用綁定的 Google、Discord 或 Steam 帳號登入，或輸入恢復碼，收藏與牌組會自動取回。

**怎麼更新？** 遊戲啟動時會自動檢查。有新版本時在公告欄按「立即更新」，下載完成後確認安裝並重新啟動。

**遇到問題怎麼回報？** 遊戲選單裡有「回報問題」，會附上版本與最近的紀錄，幫助我們找原因。也可以在 Discord 搜尋 `akk_ulin` 聯絡開發者。

**可以玩測試版嗎？** 在「設定 > 偏好」開啟「接收測試版本更新」就能收到測試版。測試版可能不穩定，連線對戰時雙方需要使用相同版本。
