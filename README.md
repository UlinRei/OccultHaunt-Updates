# 暗夜集會官方更新 Occult Haunt Updates

本倉庫只用於《暗夜集會 Occult Haunt》的官方版本與官方卡包發布，不包含遊戲原始碼。

## 下載

請由 [Releases](https://github.com/UlinRei/OccultHaunt-Updates/releases) 取得官方發布內容。每次正式發布可能包含：

- `occult-haunt-release.json`：遊戲本體最新版清單。
- Android APK 或 Windows 發行包。
- `card-pack-release.json`：官方卡包版本清單。
- 經遊戲驗證流程產生的官方卡包資產。

目前的更新偵測基底為 `0.1.12` 測試版。遊戲會讀取最新 Release 中固定命名的 `occult-haunt-release.json`，再由玩家決定是否前往下載頁。

遊戲只會讀取本倉庫中由官方帳號發布的 Release。下載與安裝仍會由玩家確認。

## 發布政策

- 本倉庫是單向的官方發布管道。
- 不接受社群卡包、非官方更新、Issue、Pull Request 或其他內容投稿。
- 卡包與遊戲本體由開發團隊在私人原始碼倉庫完成驗證後發布。
- 未經官方 Release 發布的檔案不屬於遊戲更新來源。

## 原始碼與授權

遊戲原始碼維持私人管理。本倉庫公開的 manifest 與發布說明不代表遊戲程式、美術、音訊、卡牌資料或其他資產採用開源授權。除各 Release 另有明確說明外，所有權利保留。
